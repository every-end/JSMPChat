# JSMPChat - Discord Bot

A Python-based Discord bot designed for Jupiterian Community, with minecraft smp related commands and fun stuff like !nuke.

## Requirements

- Python 3.10 or newer
- A Discord account
- A Discord application and bot created in the [Discord Developer Portal](https://discord.com/developers/applications)

## Technologies

- Python
- discord.py
- python-dotenv
- Visual Studio Code

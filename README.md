# JSMPChat - Discord Bot

A Python-based Discord bot designed for Jupiterian Community, with minecraft smp related commands and fun stuff like !nuke.

## Requirements

- Python 3.10 or newer
- A Discord account
- A Discord application and bot created in the [Discord Developer Portal](https://discord.com/developers/applications)

## Installation

1. Clone this repository:

   ```bash
   git https://github.com/every-end/JSMPChat
   ```

2. Enter the project folder:

   ```bash
   cd DiscordBot
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Rename `.env.example` to `.env`.

5. Open `.env` and add your own Discord bot token:

   ```env
   DISCORD_TOKEN=YOUR_BOT_TOKEN
   ```

## Running the Bot

Start the bot using:

```bash
python JSMPChat.py
```
